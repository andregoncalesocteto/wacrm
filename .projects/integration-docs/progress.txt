## Codebase Patterns
- Run project commands from the repo root (cwd can drift into .projects/… or node_modules/…): `npm run typecheck`, `npm run lint`, `npm test`, `npm run format:check`.
- This Next.js (16.3) is not the one you know: read the relevant guide in node_modules/next/dist/docs/ before writing Next code (AGENTS.md).
- Manual/API content lives in `content/` (content/manuals/pt/*.md, content/api/openapi.yaml). NEVER read content from `.projects/`; it once held a committed API key.
- Do not touch `.projects/**/adr/*`: accepting an ADR is a human decision, and an accepted ADR is never edited.
- All UI text goes through `useTranslations` and every new key goes into ALL four catalogues (messages/{en,es,pt,ko}.json); src/i18n/*.test.ts enforces parity. The manuals' own content is Portuguese only and does not go through the catalogues.
- Tests are colocated (`foo.ts` + `foo.test.ts`), vitest in the `node` environment; `.tsx` tests render with `react-dom/server`.
- `src/middleware.ts` only protects a hardcoded prefix list (`/settings` is in it, `/developers` is not); `src/middleware.test.ts` has the mock pattern to extend.
- `lib/auth/account.ts` has `requireRole`, `UnauthorizedError`, `ForbiddenError` for server code. The dashboard has no server page yet: US-013 sets the pattern.
- Run the full suite as `TZ=UTC npm test`: src/lib/dashboard/date-utils.test.ts has 2 pre-existing failures when the machine is not on UTC (this one is at -03); they are unrelated to this feature and CI runs in UTC.
- `next dev` REWRITES the tracked AGENTS.md on startup (and prints "Generated AGENTS.md"): run `git checkout AGENTS.md` before every commit so it does not ride along. To verify in a browser: `npx next dev -p 3100` (port 3000 is the Docker stack, built from main), then the dev-browser skill (`dev-browser <<'EOF' … EOF`; screenshots land in ~/.dev-browser/tmp/).
- `npm run build` is the place where tracing problems show up. If it prints "Dynamic filesystem access causes tracing of the whole project", the path is not statically scoped: either keep it as `path.join(process.cwd(), 'content', ...)` or add `/*turbopackIgnore: true*/` as the first argument AND declare the files in `outputFileTracingIncludes` (US-012). Grep the build log for `warning|tracing`. Do not run `pkill -f "next dev …"` from the shell: it matches the shell's own command line and kills it; find the PID with `ps -eo pid,args | grep [n]ext`.
- Do NOT run prettier on next.config.ts (or any file the repo does not keep formatted): it rewrote 29 unrelated lines. Check `git diff --stat <file>` after formatting; edit such files with a targeted replace.
- Format ONLY the files you touch before committing (`npx prettier --write <files>`; `npm run format` rewrites the whole repo); commit style: imperative, terse first line, `feat: [Story ID] - [Story Title]`.
